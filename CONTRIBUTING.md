# Contributing to The Cursed Manor

Thank you for contributing.

## Recommended workflow

1. Fork the repository or create a feature branch if you are a collaborator.
2. Start from the latest `main` branch.
3. Create a focused branch, for example:

```bash
git checkout -b feature/new-room
```

4. Make and test your changes.
5. Commit with a clear message.
6. Push the branch.
7. Open a Pull Request against `main`.

## Branch naming

Examples:

```text
feature/new-room
feature/new-event
fix/audio-loop
fix/mobile-layout
docs/update-readme
```

## Pull Requests

Keep each Pull Request focused on one change whenever possible. Describe what changed and how it was tested.

Do not commit temporary files, editor settings, operating-system metadata or local server files.
